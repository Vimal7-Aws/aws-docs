# 🪜 Staircase to Master System Design

---

## 🟢 BASIC

### 1. Database Fundamentals
- Stores structured data in SQL or NoSQL formats.  
  _Examples: MySQL, PostgreSQL, MongoDB_

### 2. Content Delivery Network (CDN)
- Delivers static assets from the nearest location to reduce latency.  
  _Examples: Cloudflare, Akamai_

### 3. API Gateway
- Acts as a single entry point for client requests, handling routing, auth, and rate limiting.  
  _Examples: Kong, AWS API Gateway_

### 4. Load Balancer
- Distributes incoming traffic across multiple servers to prevent overload.  
  _Examples: NGINX, AWS ELB_

---

## 🟡 INTERMEDIATE

### 5. Replication
- Copies data across servers for high availability and disaster recovery.  
  _E.g., master-slave setup_

### 6. Database Sharding
- Distributes large datasets across multiple machines to scale horizontally.  
  _E.g., by user ID or region_

### 7. Rate Limiting
- Restricts the number of requests per user/app to prevent abuse and protect APIs.

### 8. Caching
- Stores frequently accessed data in memory to boost response time.  
  _Examples: Redis, Memcached_
