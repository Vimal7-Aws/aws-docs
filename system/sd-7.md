### 🧠 **Networking**

* **DNS**: Maps domain names to IP addresses.
* **Load Balancers**: Distributes traffic; operates at multiple layers.
* **CDNs**: Cache content closer to users.
* **Proxies**: Forward (e.g., reverse, transparent) traffic.
* **VPNs**: Encrypted tunnels for private communication.
* **Firewalls**: Packet filtering and inspection.
* **NAT**: Allows multiple devices to share one IP.
* **Gateways**: Bridge different networks.
* **Routers**: Direct traffic between networks.

---

### 🗃️ **Storage**

* **Databases**: SQL, NoSQL (key-value, doc, columnar, graph), NewSQL.
* **Object Storage**: S3, GCP Storage, Azure Blob.
* **Block Storage**: SAN, NAS.
* **File Systems**: Distributed FS like HDFS, NFS.
* **Caching**: Redis, Memcached, CDN edge caches.

---

### 🧮 **Compute**

* **Servers**: Bare metal, virtual machines.
* **Containers**: Docker, Kubernetes.
* **Serverless**: AWS Lambda, Azure Functions.
* **FaaS**: Function-as-a-Service.
* **PaaS**: Platform-as-a-Service.

---

### 🧩 **Communication**

* **APIs**: REST, GraphQL, SOAP, gRPC.
* **Message Queues**: RabbitMQ, Kafka, ActiveMQ, Amazon SQS.
* **WebSockets**: Real-time, full-duplex communication.
* **RPC**: Remote Procedure Call types (JSON-RPC, XML-RPC).
* **Pub/Sub**: Publish-subscribe systems.
* **Service Mesh**: Istio, Linkerd.

---

### 🔐 **Security**

* **Authentication**: MFA, SSO, OAuth, OpenID Connect.
* **Authorization**: RBAC, ABAC.
* **Encryption**: Symmetric & asymmetric, hashing.
* **Security Protocols**: TLS/SSL, HTTPS, SSH.
* **WAF**: Blocks web attacks.
* **IDS**: Detects malicious behavior.

---

### 📊 **Observability**

* **Monitoring**: Prometheus, Grafana, Datadog.
* **Logging**: ELK stack, Splunk.
* **Tracing**: Jaeger, Zipkin.
* **Metrics**: Counts, gauges, summaries.
* **APM**: Dynatrace, AppDynamics.

---

### 🏗️ **Architectural Patterns**

* **Microservices**: DDD, API gateways.
* **Monolithic**: MVC, MVP.
* **Event-driven**: CQRS, Event sourcing.
* **Serverless**: FaaS, BaaS.

---

### 📈 **Scalability & Reliability**

* **Horizontal Scaling**: More instances.
* **Vertical Scaling**: Bigger instances.
* **Replication**: Master-slave/master-master.
* **Sharding**: Partitioned databases.
* **Redundancy**: Failover mechanisms.
* **Fault Tolerance**: Circuit breakers, graceful degradation.
* **Disaster Recovery**: Backups, geo-replication.
