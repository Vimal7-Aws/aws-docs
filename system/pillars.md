# System Design Concepts

## 1. APIs & Security
**Covers:**
* REST
* gRPC
* GraphQL
* Rate limiting
* Authentication methods (JWT, OAuth)
* TLS/SSL
* Protection against DDoS and MITM attacks

## 2. Caching
Improves performance and reduces load with strategies like:
* LRU (Least Recently Used)
* Session persistence
* Multi-level caching

## 3. Proxies
**Includes:**
* Reverse and forward proxies
* Load balancing methods
* Advanced routing (e.g., path-based, least outstanding requests)

## 4. Messaging
Ensures smooth inter-service communication with:
* Queues
* Pub/sub models
* Polling
* Streaming
* Idempotent processing

## 5. Features
Clarifies system goals and constraints, aligning stakeholder needs while balancing consistency, availability, and tradeoffs.

## 6. Users
Considers user types, access patterns, usage spikes, accessibility, and scalability based on demographics and behavior.

## 7. Data Model
**Explores:**
* Relational vs NoSQL databases
* Indexing
* Horizontal scaling
* Sharding
* ETL pipelines
* Distributed query models like MapReduce

## 8. Geography & Latency
Tackles region-aware system performance using:
* CDNs (Content Delivery Networks)
* DNS optimization
* Network latency optimization
* Response-time tuning

## 9. Server Capacity
Focuses on compute and storage provisioning (CPU, RAM, SSD), scaling strategies, parallel processing, and partitioning.

## 10. Availability & Microservices
Addresses:
* Fault tolerance
* Microservices orchestration
* Leader election
* Redundancy
* Observability
* Service mesh principles
